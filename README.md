# Chandrabala Desk

A mobile-first billing and inventory prototype for Chandrabala Rubber Industries.

## Modules
- Sales and purchase entry
- Inventory overview and lot/grade tracking
- Customer/supplier records
- CSV export
- WhatsApp click-to-chat helpers
- Installable PWA

## Run
Open index.html locally or host the root of this repository with GitHub Pages (Settings → Pages → Deploy from branch → main → root).

This is a browser-storage prototype. For production, configure authentication, server-side database persistence, backups, and the WhatsApp Business Cloud API.
