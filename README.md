# Chandrabala Desk\n\nStatic mobile-friendly billing/inventory prototype. Records start empty, stock starts at zero. Sales and purchase entries, grade stock, party list, invoice print/save as PDF, CSV export, business settings and SVG logo support. Data is stored in this browser's localStorage only. Not statutory accounting software; validate GST particulars with an accountant. Replace assets/logo.svg with your logo SVG.\n\nGitHub Pages: deploy the root branch from / (root).
